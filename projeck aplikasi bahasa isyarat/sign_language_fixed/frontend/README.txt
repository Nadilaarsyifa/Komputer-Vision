Cara pakai:
1. Ekstrak folder ini ke project frontend kamu.
2. Buka deteksi.html. Bagian deteksi SignLens sudah masuk ke template Bootstrap.
3. Jalankan backend FastAPI di http://127.0.0.1:8000.
4. Kalau panduan tidak muncul, copy folder images/ dari project lama ke folder ini.
5. Kalau di project lama halaman deteksi namanya projects.html, file projects.html juga sudah disiapkan dengan isi yang sama.
